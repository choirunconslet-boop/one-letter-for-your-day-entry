Entry for the make.fun bounty **"One Letter for Your Day"**
(`u-puan-one-letter-for-your-day-e54e9c36`).

`main.py` writes exactly one character to `/output/entry.txt`:
the letter **Z**, standing for **zombie** — a day spent shambling
through everything half-asleep, brain switched off, running on
caffeine and muscle memory. Z is the sharpest single-letter day:
it calls up an instant picture, it lands as a joke the moment you
hear it, and it is an honest report — everyone has had a zombie day.
